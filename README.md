# Article Parser

Простой сервис, который принимает URL сайта и пытается извлечь главный текст статьи. Если статья не найдена, приложение показывает понятное сообщение: "Парсинг не получился".

## Что умеет

- Вставить ссылку на любой сайт
- Попытаться найти основную статью через HTML-парсинг
- Показать заголовок и основной текст статьи
- Отобразить ошибку, если контент не удалось извлечь

## Технологии

- Node.js
- Express
- Cheerio
- Vanilla JavaScript
- CSS3

## Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск приложения

```bash
npm start
```

После запуска откройте в браузере:

```text
http://localhost:3000
```

## Использование

1. Введите URL сайта
2. Нажмите кнопку "Парсить"
3. Посмотрите результат:
   - статья извлечена успешно
   - или сообщение "Парсинг не получился"

## Пример


## Для Codespaces

В репозитории уже настроен devcontainer. Чтобы запустить в GitHub Codespaces:

1. Откройте репозиторий
2. Нажмите Code → Codespaces → Create codespace
3. В терминале выполните:

```bash
npm install
npm start
```

## Ограничения

Некоторые сайты блокируют автоматический парсинг, используют сложный JavaScript или отдают страницу в другом формате. В таких случаях приложение корректно показывает сообщение об ошибке.
